# calculator-kata

A tiny calculator module used as a practice repo for learning the PR workflow.

## Usage

```python
from calculator import add, subtract, multiply, divide

add(2, 3)       # 5
subtract(5, 2)  # 3
multiply(4, 3)  # 12
divide(10, 2)   # 5.0
```

## Running tests

```bash
python -m unittest discover tests
```
